# Supplementary Reference Results

This directory contains evidence used outside the principal paired matrix.

- `standalone_baselines/` preserves released CSV and workbook summaries for unmodified VLM pass@1 runs. Local rendering dependencies and generated previews are excluded.
- `visual_controls/` contains the Qwen2.5 single pass visual control manifest and analysis together with the MiniCPM workflow target subset.
- `aligned_sft/` contains the aligned base and LoRA evaluation CSVs, split audits, and statistical summaries. Adapter weights are not redistributed.
- `llava_compact/` contains the completed compact target subset run used to discuss context constrained execution.

These records have distinct protocols and are not pooled into the fourteen run main matrix.
